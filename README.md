# 🎬 M4You - Movie Ticket Booking System

A modern and responsive **Movie Ticket Booking Web Application** built using **HTML, CSS, and JavaScript**. The application allows users to browse movies, search theaters, book seats, make payments, manage profiles, and stay updated with the latest movie news.

---

## 📌 Project Overview

M4You is a front-end movie ticket booking platform that simulates the complete ticket booking process. It provides an interactive user experience with movie browsing, seat selection, payment processing, booking confirmation, theater search, and profile management.
